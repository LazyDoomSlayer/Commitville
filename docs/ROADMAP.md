# Roadmap

The roadmap is ordered by useful, observable milestones rather than speculative feature count.

## 0. Foundation — current

- Browser-first Phaser, TypeScript, and Vite runtime
- Responsive pixel-art canvas shell
- Deterministic world clock with tests
- Repository rules, architecture, privacy boundary, CI, and PR workflow
- GitHub Pages deployment pipeline
- Private licensed-art office shell with ten developer stations, two balcony/window bays, and an entrance

## 1. One believable workday

- One fictional character
- Office navigation and collision map
- Arrival, work, coffee, break, and departure behaviors
- Energy and focus needs
- Fixed-step simulation runtime
- Save and restore after refresh

Success means a viewer can watch one character complete a recognizable day without intervention.

## 2. A small team

- Five fictional characters with distinct roles and traits
- Shared tasks and pair interactions
- Conversation bubbles
- Relationships and social needs
- Meetings and lunch routines

Success means repeated days create visibly different stories.

## 3. Office events

- Deployments, incidents, deadlines, celebrations, and Friday behavior
- Event ticker and readable status language
- Seeded scenarios for testing and demos
- Sound design with a quiet mode suitable for offices

## 4. Television appliance

- Offline-capable production build
- Raspberry Pi kiosk provisioning
- Crash recovery and blank-screen watchdog
- Performance testing on target hardware at 1920×1080
- Remote version and health indicator without private telemetry

## 5. Personalization boundary

- Documented fictional character schema
- Local private configuration loader
- Separate private asset workflow
- Validation that prevents private data from entering public builds

The roadmap is allowed to change. When evidence changes the direction, update this document and record consequential decisions in an ADR.
