# Architecture decision records

Architecture decision records explain choices that constrain future work.

Each ADR should contain:

- Status
- Context
- Decision
- Consequences

Use the next available four-digit number. Accepted ADRs are not rewritten to hide changed thinking; supersede them with a new record so the project retains its decision history.
