# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability or accidental private-data exposure. Use the repository's private security advisory form:

<https://github.com/LazyDoomSlayer/Commitville/security/advisories/new>

Include the affected version, reproduction details, likely impact, and any suggested mitigation. Remove unrelated secrets or personal information from evidence.

## Supported versions

Commitville is pre-release software. Security fixes are applied to the latest `main` branch and the most recent published build.
